# Anova Tarot (iOS / iPadOS web app)

ไพ่ทาโรต์ Rider-Waite 78 ใบ ทำงานออฟไลน์ 100%

## ติดตั้งบน iPhone / iPad
1. เปิดลิงก์นี้ด้วย **Safari** (ไม่ใช่ Chrome)
2. แตะปุ่ม **แชร์** (สี่เหลี่ยมลูกศรขึ้น)
3. เลือก **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen)
4. ตั้งชื่อ → **เพิ่ม**

เปิดจากไอคอน = เต็มจอ ไม่มีแถบเบราว์เซอร์ รองรับทั้งแนวตั้ง/แนวนอน และทั้ง iPhone/iPad
