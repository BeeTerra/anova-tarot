🎴 วิธีติดตั้ง Anova Tarot

ไพ่ทาโรต์ Rider-Waite 78 ใบ · ใช้งานได้ทั้ง iPhone และ iPad · แนวตั้งและแนวนอน · ทำงานได้แม้ไม่มีอินเทอร์เน็ต
แนะนำ · ง่ายที่สุด · ไม่มีวันหมดอายุ

วิธีที่ 1 — เพิ่มไปยังหน้าจอโฮม

ใช้เวลา 20 วินาที · ไม่ต้องใช้คอมพิวเตอร์ · ไม่ต้องมี Apple ID
สแกนด้วยกล้อง iPhone/iPad
เปิดแอป Anova Tarot
  1. เปิดลิงก์ด้านบนด้วย Safari (ต้อง Safari เท่านั้น — Chrome ใช้ไม่ได้)
  2. แตะปุ่ม แชร์ 􀈂 ที่แถบล่างของจอ
  3. เลื่อนลงหา “เพิ่มไปยังหน้าจอโฮม” (Add to Home Screen)
  4. ตั้งชื่อว่า Anova Tarot แล้วกด เพิ่ม
⚠️ ครั้งแรกที่เปิด ต้องต่ออินเทอร์เน็ต 1 ครั้ง เพื่อให้ Safari เก็บไฟล์ทั้งหมดไว้ในเครื่อง หลังจากนั้นเปิดได้ตลอด แม้ไม่มีเน็ต

วิธีที่ 2 — ไฟล์ .ipa (สำหรับผู้มีคอมพิวเตอร์)

ได้แอปแยกจาก Safari · แต่ต้องเซ็นด้วย Apple ID และหมดอายุใน 7 วัน
  1. ดาวน์โหลด Sideloadly จาก sideloadly.io ลงคอมพิวเตอร์ (Windows หรือ Mac)
  2. ต่อ iPhone/iPad เข้าคอมด้วยสาย แล้วกด Trust บนเครื่อง
  3. เปิด Sideloadly → ลากไฟล์ Anova-Tarot-unsigned.ipa ใส่ช่อง IPA
  4. พิมพ์ Apple ID ของตัวเองในช่อง Apple account
  5. กด Start → ใส่รหัสผ่าน → รอประมาณ 1 นาที
  6. บนเครื่อง: ตั้งค่า → ทั่วไป → VPN กับอุปกรณ์จัดการ → ไว้วางใจ โปรไฟล์นักพัฒนา
⏳ Apple ID ฟรี: แอปใช้ได้ 7 วัน แล้วต้องรัน Sideloadly ซ้ำ (ไพ่และประวัติไม่หาย)
💳 Apple Developer 999 บาท/ปีขึ้นไป: ใช้ได้ 1 ปี

เปรียบเทียบ 2 วิธี

ต้องมีคอมวิธี 1: ไม่ต้อง · วิธี 2: ต้อง
ต้องมี Apple IDวิธี 1: ไม่ต้อง · วิธี 2: ต้อง
วันหมดอายุวิธี 1: ไม่มี · วิธี 2: 7 วัน
ไอคอนบนหน้าจอโฮมทั้งสองวิธีได้
เต็มจอ ไม่มีแถบเบราว์เซอร์ทั้งสองวิธีได้
ทำงานตอนไม่มีเน็ตทั้งสองวิธีได้
แนวตั้ง + แนวนอน (iPhone/iPad)ทั้งสองวิธีได้

คำถามที่พบบ่อย

เปิดแล้วจอขาวปิดแท็บแล้วเปิดใหม่ · ถ้ายังขาว ให้ลบล้างข้อมูลเว็บไซต์ใน ตั้งค่า → Safari แล้วเพิ่มไปหน้าจอโฮมใหม่
รูปไพ่ไม่ขึ้นต่อเน็ต 1 ครั้งแล้วเปิดแอปทิ้งไว้ 10 วินาที เพื่อให้ไฟล์ถูกเก็บลงเครื่อง
หา “เพิ่มไปยังหน้าจอโฮม” ไม่เจอต้องเปิดด้วย Safari เท่านั้น · ถ้าใช้ Chrome/Line ให้กด “เปิดใน Safari” ก่อน
ใช้บน iPad ได้ไหมได้ รองรับทั้งแนวตั้งและแนวนอน (รวมถึงกลับหัว)
ใช้บน Android ได้ไหมได้ — มีไฟล์ APK แยกต่างหาก สอบถามผู้ดูแล
Anova Tarot · ข้อมูลไพ่อยู่ในเครื่องทั้งหมด ไม่มีการส่งข้อมูลออกไป
